# Localization

Copy is data, not markup: every string is a field on a `Messages` catalog, and the ones that
interpolate are functions of a value. Two catalogs ship — `ptBR` (the default) and `en`, behind a
separate entry point so a Brazilian build never carries the English one.

## What `locale` actually does

```ts
createCheckout({ locale: 'pt-BR' /* default */ });
```

`locale` is passed to `Intl`, and only to `Intl`: the amount through `Intl.NumberFormat` with the
session's currency, timestamps through `Intl.DateTimeFormat`, the countdown as `mm:ss`. Both fall
back to a plain format if the runtime has no ICU data for the locale.

::: warning `locale` does not select the copy
Setting `locale: 'en'` gives you English *numbers and clocks* with Portuguese copy. The catalog
is chosen by `messages`, on purpose: the English strings are a separate module, and importing
them has to be your decision, not a side effect of a string literal.
:::

## English

```ts
import { createCheckout, pix } from '@nanquim/core';
import en from '@nanquim/core/locales/en';

createCheckout({
  provider: pix(),
  locale: 'en',
  messages: en,
  // …
});
```

## Overriding copy

`messages` **replaces** the catalog — it is not merged field by field. Spread the base you want
and override from there:

```ts
import { createCheckout } from '@nanquim/core';
import en from '@nanquim/core/locales/en';

createCheckout({
  locale: 'en',
  messages: {
    ...en,
    eyebrow: 'Order #4192',
    noteAwaiting: 'Open your bank app and scan the code.',
    dueIn: (mmss) => `Expires in ${mmss}`,
  },
});
```

TypeScript enforces this for you: `MessageCatalog` is the complete `Messages` interface, so a
partial object is a compile error rather than a surface with missing strings.

## Adding a language

There is no registry to register with. A catalog is a plain object of the same shape:

```ts
import type { Messages } from '@nanquim/core';
import en from '@nanquim/core/locales/en';

const es: Messages = {
  ...en,
  eyebrow: 'Pago con Pix',
  copy: 'Copiar código',
  copied: 'Código copiado',
  // …
};
```

Spread the closest built-in as the base so anything you miss stays coherent instead of switching
language mid-sentence.

## Accessibility copy is not decoration

Three fields are spoken, never drawn:

- `remainingAnnounce(mmss)` — announced into a live region at 5 minutes and 1 minute remaining.
- `copied` — announced when the payload reaches the clipboard.
- `copyManual` — announced when the clipboard write is refused, so the payer knows to select the
  text by hand.

A payer using a screen reader has no other signal that the code is about to expire. Translating
these badly is a functional bug.
